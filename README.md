# The Media Guy

Portfolio website of Obokhai Ohiwerei (The Media Guy): motion design, graphic design and video edits.

- `index.html` is the whole site: styles, scripts and layout in one file.
- `work/` holds the images and videos it shows.

Libraries (Three.js, GSAP) and fonts load from cdnjs and Google Fonts.

To publish with GitHub Pages: Settings, then Pages, then deploy from the `main` branch, root folder.
